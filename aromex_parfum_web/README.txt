AROMEX PARFUM — sitio web inicial

Archivos:
- index.html: estructura de la página.
- css/styles.css: estilos y diseño responsive.
- js/main.js: filtros del catálogo.
- images/: fotografías de los perfumes del catálogo.
- logo-aromex.png: logo proporcionado.

Cómo abrir:
1. Descomprime el archivo ZIP.
2. Abre la carpeta aromex_parfum_web.
3. Haz doble clic en index.html para abrirlo en tu navegador.

Antes de publicar:
1. Si cambias las fotografías, actualiza la ruta de la imagen correspondiente en index.html.
2. Si vas a alojarla públicamente, puedes usar GitHub Pages, Netlify o un hosting propio.

Nota: las tarjetas del catálogo usan las fotografías agregadas en images.
